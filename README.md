# Dynamic Conditional Tail Dependence in Cryptocurrency Markets

This repository contains the code and supplementary materials used in the paper:

**Mallela, R. S. S., & Leonelli, M.**
*Crashing Together, Rallying Apart: Dynamic Conditional Tail Dependence in Cryptocurrency Markets*.

## Overview

The project investigates the evolution of extremal dependence in cryptocurrency markets using dynamic Hüsler–Reiss graphical models of extremes. The analysis compares lower-tail (crash) and upper-tail (rally) dependence structures across major cryptocurrencies and contrasts the resulting extremal networks with Gaussian graphical model benchmarks.

The repository contains the code used to:

- Collect and process cryptocurrency return data.
- Fit marginal GJR-GARCH models.
- Estimate Hüsler–Reiss graphical models of extremes.
- Construct dynamic extremal networks using rolling windows.
- Compute network statistics and extremal dependence measures.
- Perform robustness analyses.
- Generate all figures and tables reported in the manuscript.

## Data

The analysis uses publicly available cryptocurrency price data obtained from Yahoo Finance.

The repository contains code to reproduce all analyses from the processed data.

## Software Requirements

The code was developed in R.

Main packages include:

- graphicalExtremes
- rugarch
- igraph
- tidyverse
- zoo
- xts
- lubridate

Additional package requirements are listed within the R scripts.

## Reproducibility

To reproduce the main results:

1. Run `Crypto Analysis.R`.
2. Run `Robustness Study Crypto.R`.

Generated figures will be saved in the `figures/` directory and numerical outputs in the `output/` directory.
